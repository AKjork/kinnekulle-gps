Uppladdning till GitHub

Varje resa laddas upp automatiskt till ditt privata repo när den är klar. Token sparas bara på den här enheten.

Skapa token hos GitHub – välj repot under "Only select repositories".

Slipp skriva in token igen: spara inloggningslänken i Anteckningar eller som bokmärke. Försvinner token (till exempel när webbläsarens data rensats) trycker du på länken eller klistrar in den i fältet Token. Länken ger samma åtkomst som token, så dela den inte.

Västtrafik (bussar)

Bussanslutningarna i Info kommer från Västtrafik och fungerar utan inställningar. Välj Buss eller Båda under Anslutningar i Info.

Egen nyckel (behövs inte)

Bara om den gemensamma nyckeln inte fungerar. Skapa en applikation i Västtrafiks utvecklarportal med API:t Planera Resa v4. Nyckeln och hemligheten sparas bara på den här enheten. Töm fälten och tryck Testa för att gå tillbaka till den gemensamma.

Mina anslutningar

Anslutningar som gäller dig. Välj Mina under Anslutningar i Info, så visas bara de här och de du markerat med ★. Tåg, Buss och Båda visar allt som förut.

Skriv buss eller tåg, linjen eller tågnumret och stationen, till exempel tåg 182 Herrljunga C. Bussarna hämtas från Västtrafiks hållplatser intill stationen. Från oss räknas upp till 2 timmar efter vår ankomst, till oss upp till 1 timme före vår avgång.
